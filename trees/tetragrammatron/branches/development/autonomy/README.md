# Development Autonomy

Who decides in the development process?

## Decision Locus

This axis records who makes decisions and how choices are made.

## Decision-Making Areas

- Architecture choices
- Technology selection
- Development priorities
- Code organization
- Validation rules
- Documentation structure

## Decision Processes

- Structural decisions enforced by validators
- Semantic decisions organized through four-axis ontology
- Technical decisions documented in dev-docs
- Implementation decisions follow established patterns

## Constraints

- Structure is enforced (validator)
- Meaning is free (semantic branches)
- Contradictions are preserved
- Consensus is observable, not mandated
