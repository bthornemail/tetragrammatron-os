# Development Context

Under what conditions does development occur?

## Environment

This axis records the development environment and conditions.

## Context Types

- **networks/**: Development team structures, collaboration
- **views/**: Architectural perspectives, system views
- **connections/**: Dependencies, component relationships
- **documents/**: Technical reference (dev-docs)
- **assets/**: Build artifacts, generated files
- **services/**: CI/CD, automation, build systems

## Development Environment
