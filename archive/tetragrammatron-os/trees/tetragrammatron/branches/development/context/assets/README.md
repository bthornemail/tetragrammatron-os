# Development Assets

This directory documents build artifacts, generated files, and assets produced or used by development services.

## Service Assets

### ESP-IDF Assets

**Location**: `services/esp-idf/v5.4.1/`

#### Generated Assets
- **Build artifacts**: Compiled firmware binaries (`.bin`, `.elf`)
- **Partition tables**: Flash layout definitions
- **Bootloader**: Second-stage bootloader binaries
- **Application binaries**: Main firmware images

#### Source Assets
- **SDK components**: Reusable code modules
- **Hardware drivers**: Peripheral drivers for ESP32/ESP8266
- **Build system files**: CMakeLists.txt, component.mk
- **Configuration files**: sdkconfig, menuconfig outputs

#### Asset Types
- **Firmware binaries**: Executable code for ESP devices
- **Libraries**: Static and dynamic libraries
- **Headers**: C/C++ header files for API access
- **Scripts**: Build and configuration scripts

### esptool Assets

**Location**: `services/python/venv/esptool/`

#### Tool Assets
- **Python packages**: Installed esptool and dependencies
- **Executables**: Command-line tools for flashing
- **Serial drivers**: USB-to-serial communication drivers

#### Generated Assets
- **Flash images**: Combined firmware images ready for flashing
- **Partition images**: Individual partition binaries
- **Verification data**: Checksums and signatures

### Python Virtual Environment Assets

**Location**: `services/python/venv/`

#### Environment Assets
- **Python packages**: All installed packages and dependencies
- **Executables**: Python scripts and entry points
- **Configuration**: Virtual environment configuration files

## Asset Flow

```
ESP-IDF Source
    ↓ build
Firmware Binaries (.bin, .elf)
    ↓ package
Flash Images
    ↓ esptool
Device Flash
```

## Asset Categories

### Build Artifacts

### Configuration Assets

### Tool Assets
- Installed packages

- Documentation

## Integration with Tetragrammatron-OS

### Hardware Probe Integration
- Firmware binaries may be flashed to devices in the hardware probe system
- Device configurations may feed into `hardware/probe.jsonl`
- Build artifacts may be referenced in canonical hardware records

### Canonicalization
- Firmware versions may be tracked in `hardware/canon.json`
- Device capabilities may be projected to `hardware/sphere.json`

## Asset Management

### Versioning
- ESP-IDF version: v5.4.1 (documented in path)
- esptool version: Managed by Python venv
- Asset versions should match service versions

### Storage
- Source assets: Stored in service directories
- Generated assets: Typically in build output directories
- Final assets: May be copied to deployment locations

## Notes

- Assets are generated by services, not stored directly in this directory
- This directory documents what assets exist and their relationships
- Actual asset files are located in their respective service directories or build outputs
