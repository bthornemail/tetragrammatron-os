# Development Freedom

What development actions are possible in Tetragrammatron-OS?

## Capabilities

This axis records what actions are possible in the development process.

## Available Tools and Technologies

- Node.js / JavaScript / TypeScript
- Lean 4 for formal verification
- React + Three.js for visualization
- Obsidian for knowledge management
- JSONL for event streams
- Scheme for canonicalization

## Development Actions

- Building and validating data structures
- Generating indices and projections
- Creating visualizations
- Writing formal proofs
- Tracking drift and changes
- Validating structure

## Constraints

- Source data is immutable
- Only projections/indices are generated
- All operations must be deterministic
